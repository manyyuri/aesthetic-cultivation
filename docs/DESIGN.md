# 设计方向（摘要）

完整 tokens 见 `packages/ui/README.md` 与 `packages/ui/src/tokens.ts`。

- **主题**：私人策展人的印刷品。纸是底色，灯是唯一的强调与唯一的动效。
- **色**：`#EDEDEA` 纸 / `#12120F` 墨 / `#F0C24B` 射灯 / `#243B53` 音乐 / `#8C1D2C` 芭蕾 / `#6B6B63` 元数据。
- **字**：宋体标题 + 拉丁原名斜体 serif + mono 档案行（编号、年份、时长、Op.）。
- **结构**：左栏动线 Ⅰ/Ⅱ/Ⅲ 是真实序列；`№` 是引用编号；序号不是装饰。
- **签名**：射灯。光源跟随阅读位置（视口中心最近的件），不是光标；`prefers-reduced-motion` 下静止。
- **留白**：正文行宽 34em，展签式窄栏；无卡片阴影、无圆角卡片、无渐变按钮。
- **缺素材**：不摆空相框 —— 美术"图版待补"、音乐"录音待补"、芭蕾"剧照待补"，一栏文字反而更像展签。
