# 决策记录（ADR）

## ADR-001 RAG 独立成层，不塞进编排器
**决定**：`rag` 只做"找证据"，`curation/orchestrator` 只做"分工与闸门"。
**理由**：换 embedding / 向量库 / 重排策略时不必碰 Agent 逻辑；检索质量与产品逻辑的迭代节奏完全不同。
**代价**：多一层调用与一次对象转换（`RetrievedChunk → Chunk`），这是必要的成本。

## ADR-002 Python 单体，不上 Go / Java
**决定**：RAG + 编排 + API 都在 Python（FastAPI + asyncio）。
**理由**：单期生成 10–20 次模型调用占 99% 时间，本地计算 < 200ms；并发上限是模型配额而不是运行时。
**代价**：没有单二进制分发；换语言要重写。缓解：编排器只依赖 5 个 port，可替换。

## ADR-003 向量库先用 `LocalVectorStore`，Chroma 留槽
**决定**：`npy + jsonl` 精确余弦，`VectorStore` 协议保留 Chroma/Milvus 实现位。
**理由**：单机、零运维、可审计（payload 明文可 grep）；语料规模不足以让 ANN 索引产生收益。
**代价**：全量扫描，万级以上 chunk 会变慢。触发换库条件：单域 > 5 万 chunk 或 p95 > 300ms。

## ADR-004 索引版本化 + 原子切换，永不原地追加
**决定**：`data/index/{domain}/{version}/` + `active.json` 原子 `os.replace`。
**理由**：向量 id 与 chunks 失配是最难查的一类 bug；版本化让"改分块策略"变成可回滚操作。
**代价**：磁盘占用翻倍（构建期）。可接受。

## ADR-005 BM25 + 向量双路 + RRF 等权
**决定**：不调权重，靠 `recall_pool` 与阈值调。
**理由**：三领域标注样本不足以支撑权重学习，调权重是自欺欺人；RRF 对量纲不敏感。
**代价**：领域差异只能粗粒度调整（在领域 yaml 里改 pool）。

## ADR-006 领域差异只允许写在 config + chunker + prompt
**决定**：三个领域共用代码，`if domain == ...` 在检索/编排层出现第三处即视为抽象失败。
**理由**：新增领域（如石窟）应是"加 yaml + 加 fixture + 可能加 chunker"，不是改核心。
**验证**：M4 类验收要求新增领域代码 ≤ 250 行。

## ADR-007 证据优先于完整性：宁发两幕，不发"大概如此"
**决定**：`evidence_status != found` 的候选直接淘汰；评审不过换候选（≤2）；不足 2 件改发往期回访。
**理由**：文博场景一次编造就能毁掉信任；空一屏比错一句便宜。
**代价**：素材不足时产出减配，需要 `coverage_gap` 记录驱动补库。

## ADR-008 自研编排状态机，不引 LangGraph / Multica 做主干
**决定**：~600 行状态机 + trace 落库。
**理由**：规则窄而硬（检索 ≤3 次、相同 query 禁止重试、冲突按 source_priority 仲裁、拒答优先），
通用图调度的抽象在这里是负担；trace 必须逐节点可解释。
**代价**：没有现成的 checkpoint / 分布式调度。触发换框架条件：需要多机执行或数百节点流程。

## ADR-009 前端撞开"纸 + 灯"，拒绝模板化
**决定**：版面语法来自美术馆展签与音乐会节目册；唯一强调色是射灯黄；射灯跟随阅读位置而非光标；缺图不摆空相框。
**理由**：① 这套语法不是"文化产品的通用皮肤"（我们否掉了奶油底+陶土色、黑底+荧光、报纸大标题三种默认）；
② 射灯编码的是真实体验（站在一件作品前），并且是全站唯一的 boldness，其余一律安静。

## ADR-010 引用渲染成展签编号，不做角标
**决定**：`№001` 而不是蓝色 `[1]`，点开才展开原文。
**理由**：溯源是展签语法的一部分，不是 UI 噪音；编号天然属于"档案"的词汇。

## ADR-011 图片走本地代理，不让浏览器直连
**决定**：`image_url` 保持远端来源（可核查），前端渲染时经 `/api/media?src=…` 代理 + 本地缓存。
**理由**：① 实测浏览器热链 403（curl 200），直连等于随机空图；② 缓存后离线可看，展签不会因为图床抽风而空；
③ 代理层做域名白名单，避免把 SSRF 风险带进来。
**代价**：多一个本地缓存目录与一次磁盘读写；`data/media/` 需纳入清理策略。
